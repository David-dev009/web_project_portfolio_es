# Triple Espresso

Proyecto del sprint 3: Página web de una cafetería

Página de una cafetería hecha con HTML y CSS. Tiene un nav fijo, un header con imagen, un formulario para reservar mesa y un footer con redes sociales.

Como mejora futura me gustaría implementar JavaScript para deshabilitar el botón de envío hasta que todos los campos estén completos, algo que vimos brevemente en el sprint 3 Formularios. Así el usuario entiende visualmente que falta información antes de poder reservar.
