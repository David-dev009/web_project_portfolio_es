# web_project_portfolio_es

# Portafolio: Jose David Duarte Martinez

Sitio web de portafolio personal desarrollado con HTML y CSS. El objetivo del proyecto es presentar mi perfil como desarrollador web, mostrar las tecnologías que utilizo y reunir en un solo lugar algunos de los proyectos que he realizado. El sitio es totalmente responsivo y se adapta a pantallas de escritorio, tablet y dispositivos móviles.

# Características

Header: breve presentación personal con fotografía, descripción y enlaces a mi CV, GitHub y datos de contacto.

Habilidades: sección con las tecnologías y herramientas que utilizo habitualmente.

Proyectos: tarjetas con una imagen, tecnologías utilizadas, una breve descripción y enlaces al repositorio y a la demo cuando está disponible.

Contacto: acceso rápido a mi correo electrónico y redes sociales.

# Tecnologías y conceptos utilizados

- HTML5
- CSS3
- Flexbox
- Metodología BEM
- Media queries
- @font-face (Open Sans y Archivo Black)
- Gradientes CSS (linear-gradient y radial-gradient)
- normalize.css
